# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest 1.x release | Yes |
| Earlier 1.x releases | No; update to the latest 1.x release |
| 0.x | No |

Security fixes are released as a new 1.x version. After updating, rebuild your iOS and Android apps so the fixed native renderers are compiled in.

## Reporting a vulnerability

Do not open a public issue, pull request, or discussion for a vulnerability.

Report it privately in one of these ways:

- **GitHub private vulnerability reporting:** open the repository's [Security tab](https://github.com/donmanueldev/nativephp-charts/security) and choose **Report a vulnerability**, or go directly to [the advisory form](https://github.com/donmanueldev/nativephp-charts/security/advisories/new).
- **Email:** `donmanuel@momotombo.dev`.

Include a minimal reproduction, the affected package version, the platform (iOS, Android, or PHP), and the impact. Do not include production secrets or personal data. You should receive an acknowledgement within seven days.
