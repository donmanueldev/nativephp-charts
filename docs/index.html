Install once.
Render natively.

The package provides native iOS and Android renderers behind a validated PHP contract. Register it, rebuild your chosen target, and render charts directly from Blade.

Terminal 
composer require donmanueldev/nativephp-charts:^1.0
php artisan vendor:publish --tag=nativephp-plugins-provider --no-interaction
php artisan native:plugin:register donmanueldev/nativephp-charts --no-interaction
php artisan native:plugin:list
php artisan native:plugin:validate

Questions answered

NativePHP Charts,
in plain terms.

What is NativePHP Charts?

It is an independent community plugin that adds native chart components to NativePHP Mobile applications built with Laravel and PHP.

Which charts are supported?

Line, area, bar, scatter, candlestick, radar, pie, and donut charts are available through native Blade elements.

Does it use a WebView or JavaScript chart library?

No. iOS uses Swift Charts and SwiftUI Canvas; Android uses Jetpack Compose Canvas. The public API stays platform-neutral.

How do I make charts accessible?

Give every chart a localized a11y-label. The renderers provide localized values and bounded summaries; validate VoiceOver and TalkBack on your target devices.

How do I install it?

Install it through Composer, register the plugin, validate the manifest, and rebuild your selected iOS or Android native target. Follow the installation guide for the complete path.
