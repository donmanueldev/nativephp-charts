NativePHP Charts installation

Your first native chart from PHP.

Install the plugin in a NativePHP Mobile app, register its native renderers, and render an accessible chart directly from an EDGE Blade view.

Install and register the plugin

NativePHP Charts is a compiled native UI plugin. Install it with Composer, publish the provider, register the plugin, and validate its manifest before rebuilding your selected target.

Terminal
composer require donmanueldev/nativephp-charts:^1.0
php artisan vendor:publish --tag=nativephp-plugins-provider --no-interaction
php artisan native:plugin:register donmanueldev/nativephp-charts --no-interaction
php artisan native:plugin:list
php artisan native:plugin:validate

Render a first chart

Charts are leaf elements. Place one in a NativeComponent EDGE view, give it an explicit height, and describe its purpose for VoiceOver and TalkBack.

<native:line-chart
    class="w-full h-80"
    :series="[[
        'id' => 'monthly-sales',
        'name' => 'Sales',
        'color' => '#0F766E',
        'points' => [
            ['id' => 'jan', 'label' => 'Jan', 'value' => 42000],
            ['id' => 'feb', 'label' => 'Feb', 'value' => 51800],
        ],
    ]]"
    a11y-label="Monthly sales"
/>

Rebuild the selected native target

The Swift and Kotlin renderers compile into your app. After installation or an update, rebuild the platform you are developing for. The package supports NativePHP Mobile 4.x, PHP 8.4+, iOS 18.2+, and Android API 26+.
