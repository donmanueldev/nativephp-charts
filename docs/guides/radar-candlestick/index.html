Radar and candlestick charts for NativePHP

Native contracts for capability and OHLC data.

NativePHP Charts exposes dedicated radar and candlestick Blade components. Use their distinct data contracts rather than adapting a Cartesian series into a misleading visualization.

Candlestick charts use OHLC points

A candlestick series represents ordered open, high, low, and close values. Provide an explicit date x-axis and stable point IDs when selection matters.

<native:candlestick-chart
    class="w-full h-80"
    :series="[[
        'id' => 'nio-usd', 'name' => 'NIO/USD', 'color' => '#2563EB',
        'points' => [[
            'id' => '2026-08-29', 'x' => '2026-08-29', 'label' => '29 Aug',
            'open' => 36.72, 'high' => 36.91, 'low' => 36.68, 'close' => 36.84,
        ]],
    ]]"
    :x-axis="['type' => 'date']"
    a11y-label="Daily NIO to USD exchange rate"
/>

Radar charts use named axes

Define ordered axes with meaningful maximums, then supply values by axis ID. Radar is for comparing a shared capability profile, not for time-series data.

<native:radar-chart
    class="w-full h-80"
    :axes="[['id' => 'speed', 'label' => 'Speed', 'maximum' => 100]]"
    :series="[['id' => 'nativephp', 'name' => 'NativePHP', 'color' => '#6366F1',
        'values' => [['axis' => 'speed', 'value' => 88]]]]"
    :grid-levels="4"
    a11y-label="NativePHP capability profile"
/>

Validate on your target devices

These are documented native components. Validate visual geometry, interaction, text scaling, and assistive technology on the devices relevant to your release before making performance or accessibility claims.
