Cartesian charts for NativePHP

Compare change, volume, and observations natively.

Line, area, bar, and scatter charts share an ordered series contract, localized axes, native selection, and one Blade API across iOS and Android.

Choose the chart that answers the question

  • Line: change over an ordered sequence.
  • Area: cumulative or layered magnitude with overlay or stacked fills.
  • Bar: grouped comparisons across categories.
  • Scatter: independent observations with numeric, date, or datetime spacing.

Start with a typed series

<native:bar-chart
    class="w-full h-72"
    :series="$revenueSeries"
    :legend="['visible' => true, 'position' => 'top']"
    :x-axis="['type' => 'category']"
    :y-axis="['valueFormat' => 'currency', 'currencyCode' => 'USD']"
    _select="pointSelected"
    a11y-label="Revenue by channel"
/>

Make selection stable

Give series and points stable IDs before enabling callbacks or frequently inserting and reordering data. Native selection and tooltip updates happen on-device; the PHP callback receives a versioned selection payload.

Format for people, not renderers

Use the locale, x-axis, y-axis, legend, and style contracts instead of Swift or Compose-specific properties. The same semantic input produces native platform output.
